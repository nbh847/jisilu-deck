# 实施前调研清单

本目录记录会直接影响实现边界的外部事实。调研结论必须附来源、访问日期和可复现步骤；页面观察与推断分开记录。未经验证的内容不得写成产品既定事实。

## 页面与数据

- 已确认：第一版目标页面为 `https://www.jisilu.cn/web/data/cb/list`。
- 已确认：目标页面使用 Vue 2 单页应用壳，页面内容由 JavaScript 动态渲染。
- 已确认：2026-08-24 未登录 Edge 会话直接打开目标 URL，可正常显示页面和“数量 30/30个”。2026-08-22 的回首页观察已被新的现场证据纠正。
- 已决策：第一版只读取当前已渲染行的债券代码和名称，在原操作按钮旁注入橙色 `+`／红色 `-`；不主动调用集思录数据接口。
- 已确认：不读取或保存行情字段，不提供批量操作。
- 已确认：QDII 页面包含欧美市场 `flex_qdiie`、商品 `flex_qdiic`、亚洲市场 `flex_qdiia` 三张目标表；切换市场后隐藏旧表仍保留在 DOM。
- 已决策：三张 QDII 表分别维护独立本地自选和独立“仅看本地自选”复选框，只读取当前可见表的代码和名称。

## 使用条款与权限边界

- 已确认：集思录现行服务协议官方 URL 为 `https://www.jisilu.cn/account/agreement/`，访问日期为 2026-08-22。
- 已证实风险：协议禁止利用网络爬虫、数据挖掘等自动化工具抓取集思录数据或内容。
- 待确认：协议未单独说明浏览器扩展读取当前页面 DOM 是否属于上述禁止范围。
- 第一版不依赖登录或会员状态；不同账号状态下的数据差异不进入第一版产品范围。

如果条款表述不明确，只记录原文和风险，不自行给出法律结论。任何需要登录或会员权限的数据默认排除，除非后续有明确依据并重新确认项目边界。

## Chrome 平台能力

已通过 Chrome 官方文档确认：

- 内容脚本可以读取和修改宿主页面 DOM，并默认运行在隔离世界中。
- 静态内容脚本必须配置 `matches`，默认 `run_at` 为 `document_idle`。
- `chrome.storage` 需要声明 `storage` 权限，所有扩展上下文均可访问。
- `chrome.storage.local` 当前配额为 10 MB，移除扩展时数据会清除。
