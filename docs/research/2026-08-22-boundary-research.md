# 目标页面与权限边界调研

> 调研日期：2026-08-22
> 范围：第一版目标页面、集思录服务协议、Chrome 扩展相关官方能力
> 方法：直接 HTTP 读取页面壳；Microsoft Edge 未登录会话访问并提取可见 DOM；Chrome 官方文档页面读取
> 补充验证：2026-08-24 使用未登录 Edge 会话重新打开目标页并核对页面布局。未检查或保存 Cookie、Token、请求头和接口响应。

## 1. 目标页面

### 来源

- 散帅指定：`https://www.jisilu.cn/web/data/cb/list`。
- 集思录首页“实时投资数据”区域的“可转债”入口指向同一 URL。

### 实测事实

- 直接 HTTP 请求目标 URL 返回 `200` 页面壳，标题为“集思录”。
- 页面壳加载 Vue `2.6.10`、Vue Router `3.1.3`、Vuex `3.1.1` 和 Axios `0.19.0`，并加载可转债相关 JavaScript 与 CSS 资源，说明数据页为客户端动态渲染。
- 2026-08-22 的未登录 Edge 会话曾回到 `https://www.jisilu.cn/` 首页；当时据此判断目标页需要登录。
- 2026-08-24 在同类未登录 Edge 会话中重新直接打开目标 URL，页面最终保持在目标 URL，标题为“列表 - 可转债 - 集思录”，页面显示“数量 30/30个”。这项新证据推翻了此前的登录前提判断；前次回首页的具体原因没有证据，保留为一次异常观察，不再作为产品依据。
- 2026-08-24 实测视口为 `1192×686` CSS 像素，设备像素比为 `2`；文档宽度约 `1661px`，表格横向溢出视口。页面右侧未发现现成固定悬浮控件。

### 结论

- 第一版目标 URL 已确认，不再把 URL 作为待确认项。
- 目标页可以作为未登录可访问页面描述；本轮页面现场显示 30 条数据。
- 第一版不依赖登录状态，同时仍不负责登录、不绕过访问限制。
- 页面是横向宽表。2026-08-24 产品范围进一步收敛为操作列行内按钮，不再使用抽屉。
- 第一版需要定位操作列并读取当前行代码和名称，不读取行情字段。

## 2. 集思录服务协议

### 官方来源

- [集思录服务协议](https://www.jisilu.cn/account/agreement/)，访问日期：2026-08-22。
- 该链接来自集思录首页底部“用户协议”。

### 与本项目直接相关的原文

协议第四条第 3 款第（6）项将以下行为列入可能导致服务中断或终止的情形：

> 利用网络爬虫、数据挖掘等自动化工具抓取集思录数据或内容。

协议第九条第 2 款第（3）项还提示，通过非集思录授权方式使用服务可能带来损失和风险。

### 风险判断

- **已证实风险**：自动化抓取集思录数据或内容被协议明确禁止。
- **边界不明确**：协议没有单独定义浏览器扩展读取用户当前页面 DOM 是否属于“抓取”。因此不能据此宣称页面 DOM 读取已合规，也不能反向断言所有页面增强扩展必然违规。
- **第一版处理**：只处理当前已渲染行，读取代码和名称，在操作列注入橙色 `+`／红色 `-`；不主动请求接口，不保存行情，不批量导出。
- **已知风险**：上述 DOM 处理仍属于自动化页面处理，不能表述为已获得集思录授权。若扩大到行情、接口、批量导出或其他页面，必须重新评估边界。

本文只记录产品风险，不构成法律意见。

## 3. Chrome 官方能力

### `chrome.storage`

官方来源：[chrome.storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)，页面最后更新时间为 2026-05-12（UTC），访问日期为 2026-08-22。

已确认事实：

- 使用 Storage API 需要在 Manifest 中声明 `storage` 权限。
- 所有扩展上下文，包括内容脚本，都可以访问 Storage API。
- API 为异步接口，存储 JSON 可序列化值。
- `storage.local` 当前配额为 10 MB。
- `storage.local` 数据在清除浏览器缓存和浏览记录后仍保留，但移除扩展时会清除。

产品结论：第一版少量本地自选数据适合使用 `chrome.storage.local`，不需要 `unlimitedStorage`。

### 内容脚本

官方来源：[内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)，访问日期为 2026-08-22。

已确认事实：

- 内容脚本能访问宿主页面 DOM，并与宿主页面 JavaScript 运行在相互隔离的世界中。
- 静态内容脚本必须配置 `matches`；默认注入时机为 `document_idle`。
- 内容脚本可以直接访问 `chrome.storage`。

产品结论：从 Chrome 平台能力看，可以在目标 URL 的表格操作列注入本地 `+`／`-` 并读取本地存储。页面 DOM 处理仍受产品与协议边界约束。
