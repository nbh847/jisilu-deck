# 第一版实施边界设计

> 状态：已实现并验证
> 更新日期：2026-08-24

## 1. 唯一功能

在目标页每条可转债记录的现有操作按钮旁增加本地自选按钮，使用橙色 `+` 加入、红色 `-` 取消。

## 2. 最小权限

只需要：

- `storage`：保存本地自选代码、名称和添加时间。
- 目标页内容脚本匹配范围：`https://www.jisilu.cn/web/data/cb/list` 及其查询参数或片段标识。

不申请 `tabs`、`activeTab`、`scripting`、`cookies`、`webRequest`、`unlimitedStorage`、`<all_urls>` 或整个集思录域名权限。

## 3. 页面适配责任

页面适配逻辑集中在一个模块，只负责：

- 找到可转债表格的已渲染行。
- 找到每行现有操作按钮的容器。
- 读取当前行的债券代码和名称。
- 插入一个插件按钮，并保证同一行不重复插入。
- 根据本地选中状态，只切换当前行转债名称的红色标记样式。
- 表格内容刷新后重新检查按钮和本地选中状态。
- 本地按钮保持独立元素和事件，只复用页面 `jisilu-icons` 图标字体与字形：`+` 使用 `U+E61E` 并改为橙色 `#e67e22`，`-` 使用 `U+E61D` 和原站红色 `#dd1817`；名称标记与本地 `-` 共用同一红色。

选择器、表格刷新监听和按钮注入不得分散到其他模块。

## 4. 本地自选责任

- 以 `bondCode` 为唯一键。
- 橙色 `+` 点击后保存代码、名称和添加时间，成功后切换为红色 `-`，并把转债名称标红。
- 红色 `-` 点击后删除当前代码对应的本地记录，成功后切换为橙色 `+`，并移除名称红色标记以恢复页面原样。
- 保存或删除成功后才更新按钮状态。
- 页面刷新和浏览器重启后从 `chrome.storage.local` 恢复状态。

## 5. 页面边界

- 不主动请求任何集思录接口。
- 不保存代码和名称以外的页面字段。
- 不处理现价、涨跌幅、溢价率、评级等数据。
- 除本地选中行的转债名称颜色外，不修改集思录原按钮、其他字段样式、排序、筛选和表格数据。
- 不提供抽屉、表单、持仓或管理页面。

## 6. 异常语义

- 找不到目标表格或行结构：不注入错误位置，保留页面原状。
- 读取不到合法代码或名称：当前行不允许加入，显示局部失败提示。
- 本地保存失败：保持未选状态。
- 本地删除失败：保持红色 `-` 和名称红色标记。
- 表格刷新：重新注入缺失按钮，不产生重复按钮。

## 7. 当前阶段

第一版已实现并通过真实页面自动化验收。模块对应关系：`src/content/watchlist-store.js` 承担第 4 节本地自选责任，`src/content/page-adapter.js` 承担第 3 节页面适配责任，`src/content/main.js` 负责连接与表格重渲染监听。
