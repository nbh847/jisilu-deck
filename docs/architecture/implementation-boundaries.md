# 实施边界设计

> 状态：`0.4.0` 已实现并通过验收
>
> 更新日期：2026-09-07

## 1. 功能范围

在可转债与 QDII 目标页维护本地自选；可转债额外提供待购子状态及“仅看本地自选／仅看待购”组合筛选。QDII 的欧美市场、商品、亚洲市场按三个独立分类处理，不包含待购。

## 2. 最小权限

只需要：

- `storage`：保存本地自选代码、名称、添加时间和可转债待购时间。
- 内容脚本匹配范围：`https://www.jisilu.cn/web/data/cb/*` 与 `https://www.jisilu.cn/data/*`。后者只用于在数据板块 SPA 过渡页保持监听；没有可转债目标表格时不写 DOM。

不申请 `tabs`、`activeTab`、`scripting`、`cookies`、`webRequest`、`unlimitedStorage`、`<all_urls>` 或整个集思录域名权限。

## 3. 页面适配责任

页面适配逻辑集中在一个模块，只负责：

- 找到可转债表格的已渲染行。
- 页面内切换其他品种后，只识别当前可见且包含可转债详情链接的目标表格，不复用仍留在 DOM 中的旧表格。
- 找到每行现有操作按钮的容器。
- 读取当前行的债券代码和名称。
- 插入一个插件按钮，并保证同一行不重复插入。
- 定位原站顶部“仅看自选／仅看持仓”按钮组，在其后插入独立的插件双按钮筛选组并保证不重复。
- 根据本地选中状态，只切换当前行转债名称的红色标记样式。
- 在本地自选行的转债名称后、页面自有状态图标前插入灰色 `+`／橙色“待购”，非本地自选行不保留入口。
- 通过插件自有 CSS 类隐藏不属于本地自选的数据行，关闭筛选时移除该类；不改写站内数据源或筛选状态。
- 没有匹配行时显示插件自有空状态，恢复显示后隐藏空状态。
- 表格内容刷新后重新检查按钮和本地选中状态。
- MutationObserver 未捕获到 SPA 切换时，每秒做一次幂等状态对账；只扫描当前可见可转债表，不向其他品种写入。
- 本地按钮保持独立元素和事件，只复用页面 `jisilu-icons` 图标字体与字形：`+` 使用 `U+E61E` 并改为橙色 `#e67e22`，`-` 使用 `U+E61D` 和原站红色 `#dd1817`；名称标记与本地 `-` 共用同一红色。
- QDII 只识别当前可见的 `flex_qdiie`、`flex_qdiic`、`flex_qdiia`，分别映射为 `europe`、`commodity`、`asia`；市场切换后留在 DOM 中的隐藏表不得扫描。
- QDII 代码取首列 `/data/qdii/detail/` 链接，名称取第二列文本；操作入口同时识别末列未自选状态的 `addOwnedQd(...)` 与已自选状态的 `delOwnedQd(...)` 链接。站内脚本整体重写操作单元格后，扫描器必须重新补回独立本地按钮。
- QDII 本地复选框只插在当前表站内 `input[name="only_owned"]` 所属标签右侧，不写入或触发站内表单逻辑。

选择器、表格刷新监听和按钮注入不得分散到其他模块。

## 4. 本地自选责任

- 以 `bondCode` 为唯一键。
- 橙色 `+` 点击后保存代码、名称和添加时间，成功后切换为红色 `-`，并把转债名称标红。
- 红色 `-` 点击后删除当前代码对应的本地记录，成功后切换为橙色 `+`，并移除名称红色标记以恢复页面原样。
- 保存或删除成功后才更新按钮状态。
- 页面刷新和浏览器重启后从 `chrome.storage.local` 恢复状态。
- 筛选开关只保存在当前内容脚本会话中，不写入 `chrome.storage.local`；页面完整刷新后默认关闭。
- QDII 使用独立存储集合，按 `category + fundCode` 隔离三类记录；三类筛选状态也分别保存在内容脚本会话中。
- 可转债待购以 `bondCode` 为唯一键并从属于本地自选；移出本地自选时通过同一次存储写入级联清除待购。
- 可转债筛选模式为关闭、本地自选、待购三态，两个可见按钮互斥；筛选状态只保存在当前内容脚本会话中。

## 5. 页面边界

- 不主动请求任何集思录接口。
- 不保存代码和名称以外的页面字段。
- 不处理现价、涨跌幅、溢价率、评级等数据。
- 除本地选中行的名称颜色、名称旁待购入口、插件筛选组及被筛选行的可见性外，不修改集思录原按钮、其他字段样式、排序、筛选和表格数据。
- 不提供抽屉、表单、持仓或管理页面。

## 6. 异常语义

- 找不到目标表格或行结构：不注入错误位置，保留页面原状。
- 读取不到合法代码或名称：当前行不允许加入，显示局部失败提示。
- 本地保存失败：保持未选状态。
- 本地删除失败：保持红色 `-` 和名称红色标记。
- 待购保存或清除失败：保持原待购状态并显示局部失败提示。
- 表格刷新：重新注入缺失按钮，不产生重复按钮。
- 页面内品种切换：离开可转债时不向其他表格注入，切回后重新定位当前可见可转债表格并恢复状态。
- 找不到原站筛选按钮组：不在其他位置猜测注入筛选按钮，逐行本地自选功能继续工作。

## 7. 当前阶段

`0.4.0` 继续由 `src/content/watchlist-store.js` 承担本地自选、待购和 QDII 存储责任，`src/content/page-adapter.js` 承担页面适配责任，`src/content/main.js` 负责状态连接、分类状态与表格重渲染监听。实现已通过单元测试及可转债、QDII 真实 Chrome E2E，最终记录以 `ROADMAP.md` 为准。
