# 第一版验证计划

> 状态：已按本计划执行。2026-08-24 通过 Playwright 加载未打包扩展在真实页面完成自动化验收（29/29 项，含页面刷新、表格重渲染、浏览器重启持久化），单元测试 11/11；散帅自有 Chrome 手工验收待做。
> 更新日期：2026-08-24

## 1. 权限

- Manifest V3。
- 只有 `storage` 和目标页匹配范围。
- 不申请其他权限。

## 2. 橙色 `+`

- 每条已渲染记录的深蓝色 `+` 旁只出现一个橙色 `+`。
- 点击橙色 `+` 后，只保存当前行的代码、名称和添加时间。
- 保存成功后变为红色 `-`。
- 保存成功后，当前行转债名称变为与本地 `-` 完全相同的红色。
- 连续点击不会生成重复记录。
- 保存失败时保持橙色 `+`，转债名称保持页面原本颜色。

## 3. 红色 `-`

- 点击红色 `-` 后，只删除当前转债的本地记录。
- 删除成功后恢复为橙色 `+`，转债名称恢复页面原本颜色。
- 删除失败时保持红色 `-` 和名称红色标记。

## 4. 刷新与持久化

- 页面刷新后 `+`、`-` 状态正确恢复。
- 页面刷新、表格刷新和浏览器重启后，已加入行的转债名称保持红色，未加入行保持页面原本颜色。
- 表格手动刷新后按钮不重复，状态正确恢复。
- 浏览器重启后状态正确恢复。

## 5. 边界

- 不修改集思录原 `+`、`-` 的行为和样式。
- 除已加入行的转债名称颜色外，不修改代码和其他表格字段样式。
- 不主动请求集思录接口。
- 不保存代码、名称和添加时间以外的数据。
- 不出现批量操作、持仓、抽屉、表单、筛选、备注或管理页面。

## 6. 真实页面验证

在 Chrome `chrome://extensions` 加载未打包扩展，在目标页逐项验证上述场景，并把结果记录到 `ROADMAP.md`。全部通过后才能标记第一版完成。
