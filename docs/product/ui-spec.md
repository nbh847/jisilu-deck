# 本地自选交互规格

> 状态：已确认
> 更新日期：2026-08-25

## 1. 按钮位置

- 在可转债表格现有“操作”列中，紧邻集思录深蓝色 `+` 增加一个橙色 `+`。
- 不新增抽屉、弹窗或表单。
- 原操作单元格宽度为 `32px`，两个按钮必须在该单元格内并排显示，不扩展列宽、不覆盖原按钮。

## 2. 与原按钮的区分

2026-08-24 真实页面实测：原 `+` 为 `jisilu-iconfont` 的 `U+E61E`，尺寸 `13×13px`，颜色为深蓝 `rgb(32, 103, 152)`；原 `-` 为同一字体的 `U+E61D`，尺寸 `13×13px`，颜色为红色 `#dd1817`。

本地按钮：

- 使用独立的本地按钮元素，内部复用原站 `span.jisilu-icons`、图标字体和对应字形；不复用原站按钮元素或事件。
- `+` 使用原站 `U+E61E` 字形，`-` 使用原站 `U+E61D` 字形，图标尺寸均为 `13×13px`。
- 本地 `+` 使用橙色 `#e67e22`，与原站深蓝色 `+` 区分。
- 本地 `-` 直接使用原站红色 `#dd1817`；已选转债名称与本地 `-` 同色。
- 本地按钮通过独立元素、悬浮提示和可读名称区分来源；颜色不是唯一的来源标识。
- 与原按钮之间保留最小可识别间距，但不改变 `32px` 操作列宽度。
- 鼠标指针为可点击状态。

## 3. 按钮状态

### 未加入

- 显示橙色 `+`。
- 转债名称保持集思录页面原本颜色。
- 可读名称为“加入本地自选”。
- 悬浮提示沿用页面语气：“加[转债名称]为本地自选转债”。

### 保存中

- 临时禁用按钮，避免连续点击产生重复写入。
- 不增加全局加载状态。

### 红色 `-`

- 显示红色 `-`；`-` 表示当前转债已在本地自选中。
- 当前行的转债名称显示为与本地 `-` 完全相同的红色，只改变名称文字颜色，不改变代码和其他字段样式。
- 可读名称为“移出本地自选”。
- 悬浮提示为“从本地自选移出[转债名称]”。
- 点击后移除当前债券的本地自选，成功后恢复为橙色 `+`，转债名称恢复页面原本颜色。

### 保存失败

- 恢复橙色 `+`。
- 在按钮附近显示简短失败提示，不弹出独立面板。

## 4. 页面刷新

- 页面初次加载和表格刷新后，根据本地 `bondCode` 恢复各行的橙色 `+` 或红色 `-`。
- 恢复为红色 `-` 的行，同时把转债名称恢复为相同红色；未加入的行保持页面原本名称颜色。
- 同一行只允许存在一个插件按钮。
- 插件不得修改集思录原按钮的颜色、事件或提示文字，也不得修改名称以外的表格字段样式。

## 5. “仅看本地自选”筛选

- 位置：紧跟原站“仅看自选／仅看持仓”按钮组，位于“显示已拉黑”之前。
- 按钮是原站 Vue 按钮组的同级独立元素，不插入原站按钮组内部；与原站按钮组保留 `8px` 间距。
- 高度、字号和内边距与原站 mini 筛选按钮一致；关闭时白底灰边，开启时使用橙色 `#e67e22` 背景和白色文字。
- 文案固定为“仅看本地自选”，并通过 `aria-pressed` 表达开关状态。
- 点击开启后，只显示“站内当前结果 ∩ 本地自选”的数据行；不请求额外数据、不修改站内筛选状态。
- 再次点击关闭后，恢复所有由本地筛选隐藏的当前数据行。
- 开启期间，表格刷新、排序、SPA 切换回可转债以及本地自选增删后重新应用筛选。
- 开启期间移出当前行的本地自选后，该行立即消失；加入本地自选的行保持显示。
- 没有匹配行时，在表格后显示“当前筛选条件下暂无本地自选”。

## 6. 明确不做

- 独立查看、编辑或批量删除本地自选。
- 持仓、备注、标签和批量操作。
- 任何独立管理界面。

## 7. QDII 三表交互

- 支持欧美市场 `flex_qdiie`、商品 `flex_qdiic`、亚洲市场 `flex_qdiia` 三张表。
- 每张表的站内蓝色 `+` 右侧增加本地橙色 `+`；加入后变为红色 `-`，当前基金名称同步标红。
- QDII 原“操作”列约 `27–29px`，无法容纳两个按钮；插件把该列最小宽度扩到约 `46px`，两个图标之间保留 `6px`，避免两个红色 `-` 视觉粘连，并且不覆盖“基金公司”列。
- 每张表在自己的站内“仅看自选”右侧增加一个复选框，文案固定为“仅看本地自选”。
- 本地复选框沿用原页面复选框、字号和垂直对齐，不使用可转债页的橙色块状筛选按钮。
- 欧美市场、商品、亚洲市场的行内状态、筛选状态和空状态分别维护，互不影响。
- 没有匹配行时，当前表显示“当前筛选条件下暂无本地自选”，其他表保持原状。
