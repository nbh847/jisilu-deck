# 第一版按钮交互规格

> 状态：已确认
> 更新日期：2026-08-24

## 1. 按钮位置

- 在可转债表格现有“操作”列中，紧邻集思录深蓝色 `+` 增加一个橙色 `+`。
- 不新增抽屉、弹窗、表单、顶部按钮或其他页面入口。
- 原操作单元格宽度为 `32px`，两个按钮必须在该单元格内并排显示，不扩展列宽、不覆盖原按钮。

## 2. 与原按钮的区分

2026-08-24 实测原 `+`：图标约 `13×13px`，颜色为深蓝 `rgb(32, 103, 152)`，使用集思录 `jisilu-icons` 字体。散帅补充确认原 `-` 为红色。

本地按钮：

- 使用普通文本 `+` 和 `-`，不复用 `jisilu-icons` 类或图标字体。
- 图标占位约 `13×13px`，与原按钮尺寸协调。
- 本地 `+` 使用橙色 `#e67e22`，与原站深蓝色 `+` 区分。
- 本地 `-` 使用红色，允许与原站红色 `-` 同色。
- 本地按钮继续使用独立元素和普通文本字符，不通过颜色单独承担来源识别。
- 与原按钮之间保留最小可识别间距，但不改变 `32px` 操作列宽度。
- 鼠标指针为可点击状态。

## 3. 按钮状态

### 未加入

- 显示橙色 `+`。
- 转债名称保持集思录页面原本颜色。
- 可读名称为“加入本地自选”。
- 悬浮提示沿用页面语气：“加[转债名称]为本地自选转债”。

### 保存中

- 临时禁用按钮，避免连续点击产生重复写入。
- 不增加全局加载状态。

### 红色 `-`

- 显示红色 `-`；`-` 表示当前转债已在本地自选中。
- 当前行的转债名称显示为与本地 `-` 完全相同的红色，只改变名称文字颜色，不改变代码和其他字段样式。
- 可读名称为“移出本地自选”。
- 悬浮提示为“从本地自选移出[转债名称]”。
- 点击后移除当前债券的本地自选，成功后恢复为橙色 `+`，转债名称恢复页面原本颜色。

### 保存失败

- 恢复橙色 `+`。
- 在按钮附近显示简短失败提示，不弹出独立面板。

## 4. 页面刷新

- 页面初次加载和表格刷新后，根据本地 `bondCode` 恢复各行的橙色 `+` 或红色 `-`。
- 恢复为红色 `-` 的行，同时把转债名称恢复为相同红色；未加入的行保持页面原本名称颜色。
- 同一行只允许存在一个插件按钮。
- 插件不得修改集思录原按钮的颜色、事件或提示文字，也不得修改名称以外的表格字段样式。

## 5. 明确不做

- 独立查看、编辑或批量删除本地自选。
- 持仓、备注、标签、筛选和批量操作。
- 任何独立管理界面。
