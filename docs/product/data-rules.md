# 本地自选数据规则

> 状态：`0.3.0` 范围已确认
> 更新日期：2026-08-25

## 1. 唯一数据

第一版只保存本地自选记录：

| 字段 | 来源 | 规则 |
| --- | --- | --- |
| `bondCode` | 用户点击按钮时读取当前行 | 6 位数字，唯一键 |
| `bondName` | 用户点击按钮时读取当前行 | 非空字符串 |
| `createdAt` | 插件生成 | ISO 8601 时间字符串 |

数据保存在 `chrome.storage.local`。不保存持仓、数量、成本价、备注、行情或集思录账号信息。

## 2. 添加语义

- 用户点击某行橙色 `+` 后，保存该行的代码、名称和添加时间。
- `bondCode` 已存在时不重复写入，按钮保持红色 `-`。
- 保存成功后才从橙色 `+` 切换为红色 `-`；保存失败时保持 `+` 并显示失败提示。
- 用户点击红色 `-` 后，删除当前 `bondCode` 对应的本地记录；删除成功后恢复为橙色 `+`。
- 删除失败时保留本地记录和红色 `-`，并显示失败提示。
- 页面刷新和浏览器重启后，根据本地记录恢复橙色 `+` 或红色 `-`。

## 3. 第一版明确不做

- 编辑、排序、备注和批量管理。
- 导入、导出、同步或历史记录。

“仅看本地自选”只读取上述本地代码集合并隐藏不匹配的当前页面行，不新增持久化字段。

## 4. QDII 三类本地自选

QDII 使用独立于可转债的存储集合，并按以下分类隔离：

| `category` | 页面表格 | 表格 ID |
| --- | --- | --- |
| `europe` | 欧美市场 | `flex_qdiie` |
| `commodity` | 商品 | `flex_qdiic` |
| `asia` | 亚洲市场 | `flex_qdiia` |

每条 QDII 记录只保存：

| 字段 | 规则 |
| --- | --- |
| `fundCode` | 当前行读取的 6 位数字基金代码 |
| `fundName` | 当前行读取的非空基金名称 |
| `createdAt` | 插件生成的 ISO 8601 时间字符串 |

- 唯一语义为 `category + fundCode`；三个分类可以独立保存同一个六位代码。
- 添加、移出、恢复和失败语义与可转债一致，但只能读写当前行所属分类。
- QDII 三个“仅看本地自选”状态只保存在当前内容脚本会话，彼此独立；页面完整刷新后全部默认关闭。
- QDII 不保存现价、涨幅、净值、份额、溢价率、基金公司或其他行情字段。
